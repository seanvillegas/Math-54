1. QR Factorization
Algorithm
Given A = [v1 | v2]: u1 = v1 u2 = v2 - (v2.u1 / u1.u1) * u1 q1 = u1/||u1||, q2 = u2/||u2|| Q = [q1 | q2], R = Q^T * A
Example (Review2.pdf p.3)
A = [1 1] v1.v1=3, v2.v1=-1 [1 -1] [1 -1] u2 = [-1;-1;-1] + (1/3)[1;1;1] = [4/3; -2/3; -2/3] Q = [1/sqrt(3) sqrt(2)/sqrt(3) ] [1/sqrt(3) -sqrt(2)/(2sqrt3)] [1/sqrt(3) -sqrt(2)/(2sqrt3)] R = Q^T * A = [sqrt(3) -1/sqrt(3) ] [0 2sqrt(2)/sqrt(3)]
Theorem: A = QR where Q has orthonormal cols, R is upper triangular with positive diagonal. Unique if A has lin. ind. columns.
Trap: R = Q^T * A, NOT Q*A. Post-multiply by A.
Proj via Q: If H = Col(U), U orthonormal cols → proj = U*U^T (same result as G-S route, much faster).
2. Superposition (ODE)
Principle
If L[y]=0 has solutions y1,y2 and L[yp1]=f1, L[yp2]=f2, then y = c1*y1+c2*y2+yp1+yp2 solves L[y]=f1+f2.
Example (Review1.pdf p.3-5): y'' + 4y = 3cos(t) + t^2
Split RHS into two problems: L[y] = 3cos(t): guess A*cos(t)+B*sin(t) Plug in: (4A-A)cos = 3cos → A=1, B=0 yp1 = cos(t) L[y] = t^2: guess At^2+Bt+C 2A + 4At^2+4Bt+4C = t^2 4A=1 → A=1/4, 4B=0, 2A+4C=0 → C=-1/8 yp2 = t^2/4 - 1/8 General: y = c1*cos(2t)+c2*sin(2t)+cos(t)+t^2/4-1/8
Resonance trap: if RHS matches hom solution, multiply guess by t^s where s = multiplicity of root.
Resonance example (Review1.pdf p.6-7)
y''+3y'+2y = e^(-t) Hom roots: r=-1,-2 → e^(-t) in hom! → guess yp = A*t*e^(-t) Plug in → A=1 yp = t*e^(-t) General: t*e^(-t) + c1*e^(-t) + c2*e^(-2t)
UndCoeff table: eᵃᵗ→Aeᵃᵗ | cos/sin(βt)→Acos+Bsin | tⁿ→Aₙtⁿ+…+A₀ | products → multiply forms
3. ODE IVP (2nd order linear)
Algorithm
1. Solve hom (char poly roots → y_hom) 2. Find yp by undetermined coefficients 3. y_gen = y_hom + yp 4. Apply ICs → solve for c1, c2
Example (final54_19.pdf p.1): y''+4y=e^t, y(0)=1, y'(0)=2
Step 1: r^2+4=0 → r=±2i y_hom = c1*cos(2t)+c2*sin(2t) Step 2: guess yp=A*e^t (e^t not in hom) e^t + 4*A*e^t = e^t → 5A=1 → A=1/5 yp = e^t/5 Step 3: y = c1cos(2t)+c2sin(2t)+e^t/5 Step 4: y(0)=1 → c1 + 1/5 = 1 → c1 = 4/5 y' = -2c1*sin(2t)+2c2*cos(2t)+e^t/5 y'(0)=2 → 2c2 + 1/5 = 2 → c2 = 9/10 ANSWER: y = (4/5)cos(2t) + (9/10)sin(2t) + e^t/5
Char roots → solutions: real r1≠r2 → eʳ¹ᵗ,eʳ²ᵗ | repeated r → eʳᵗ,teʳᵗ | α±βi → eᵅᵗcos(βt), eᵅᵗsin(βt)
Check ICs last, after full general solution. Differentiate yp correctly before plugging in.
Matrix system x'=Ax: eigenvalues λ → eˡᵗv; complex α±βi → eᵅᵗ(cos(βt)Re(v)-sin(βt)Im(v))
4. Fourier Series
Formulas (period 2π)
f(x) = a0/2 + Σ[an*cos(nx) + bn*sin(nx)] a0 = (1/π)∫_{-π}^{π} f(x)dx an = (1/π)∫_{-π}^{π} f(x)cos(nx)dx bn = (1/π)∫_{-π}^{π} f(x)sin(nx)dx
Example (final54_19.pdf p.2, Review1.pdf p.15-16)
f(x) = {0 for -π≤x≤0; cos(x) for 0
Convergence: → f(x) if continuous; → [f(x⁺)+f(x⁻)]/2 at jumps; at ±π → average of endpoint values.
Trap: Do NOT use f(±π) directly at endpoints — use average of limits.
Even f → cosine series (bn=0 for all n). Odd f → sine series (an=0 for all n). Saves half the integrals.
Parseval: (1/π)∫|f|²dx = a0²/2 + Σ(an²+bn²). Use to sum infinite series like Σ1/n⁴.
5. Least Squares
Core equation
Solve normal equations: A^T A x̂ = A^T b x̂ = (A^T A)^{-1} A^T b (if A^T A invertible) Proj: Ax̂ = A(A^T A)^{-1} A^T b = proj_{Col A}(b)
Example (Review2.pdf p.6-7): fit y=β0+β1*x to (1,0),(2,1),(4,2),(5,3)
Set up A*β = b: A=[1 1;1 2;1 4;1 5], b=[0;1;2;3] A^T A = [4 12] A^T b = [6 ] [12 46] [25] Row reduce [A^T A | A^T b]: [4 12 | 6 ] ~ [1 0 | -0.6] [12 46 | 25] [0 1 | 0.7] β0 = -0.6, β1 = 0.7 ANSWER: y = -0.6 + 0.7x
Key theorems
b - Ax̂ ⊥ Col(A): the residual is orthogonal to every column of A. This IS the normal equation A^T(b-Ax̂)=0.
A^T A invertible ⟺ cols of A lin. ind. ⟺ Nul(A)={0}. (from final54_19.pdf Prob 5)
Nul(A^T A) = Nul(A) and rank(A^T A) = rank(A). (from final54_19.pdf Prob 5)
Via QR (cleaner)
If A = QR then: x̂ = R^{-1} Q^T b (avoids ill-conditioning of A^T A)
Projection matrix P
P = A(A^T A)^{-1} A^T = U U^T (if cols orthonormal) Properties: P^2=P, P^T=P Eigenvalues: only 0 and 1 rank(P) = dim(Col A)
Trap: If asked for T(p) where T is orthogonal projection, compute Ax̂ not x̂. The projection is the OUTPUT in original space.
Geometric: x̂ minimizes ||Ax-b||². Think: drop a perpendicular from b to Col(A).
Char poly roots → solutions (all cases)
Real distinct r1≠r2
Scalar ODE: c1*e^(r1*t)+c2*e^(r2*t) System: c1*e^(λ1*t)*v1+c2*e^(λ2*t)*v2
Repeated root r (mult 2)
Scalar ODE: (c1+c2*t)*e^(r*t) System (generalized ev u): c1*e^(r*t)*v + c2*e^(r*t)*(t*v+u) where (A-rI)u=v
Complex α±βi
Scalar ODE: e^(αt)(c1*cos(βt)+c2*sin(βt)) System: let v=a+ib x1=e^(αt)(cos(βt)*a - sin(βt)*b) x2=e^(αt)(sin(βt)*a + cos(βt)*b)
Wronskian / linear indep
W[f,g](t) = |f g | |f' g'| W[f,g,h] = 3x3 det W(t0)≠0 at some t0 → linearly INDEPENDENT Key: W is either always 0 or never 0 on interval.
